# Reconciliation Runbook

1. Identify reconciliation period and source.
2. Freeze the relevant report snapshot.
3. Compare provider records with internal payment and ledger records.
4. Classify differences: timing, missing event, duplicate, amount, currency, state, unknown.
5. Never directly edit posted ledger history.
6. Resolve through documented compensating transactions or operational correction flows.
7. Preserve evidence and audit trail.
8. Produce a reconciliation report and sign-off record.
