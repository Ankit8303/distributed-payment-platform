# Engineering Methodology

This project follows:
- requirements-first engineering;
- modular monolith architecture;
- domain/invariant-driven design;
- contract-first APIs/events;
- database integrity as a financial safety layer;
- transactional boundaries;
- transactional outbox;
- idempotent asynchronous processing;
- defense-in-depth security;
- automated testing;
- observable operations;
- evidence-based performance engineering;
- controlled releases;
- incident and recovery preparedness.

The project deliberately favors depth and correctness over technology count.
